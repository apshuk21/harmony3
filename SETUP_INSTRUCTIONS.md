# Project Setup Instructions

This document tracks all setup configurations and changes made to the project.

## TanStack Router Setup

### 1. Dependencies Installed

```bash
npm install -D @tanstack/router-plugin @tanstack/router-devtools
```

| Package | Type | Purpose |
|---------|------|---------|
| `@tanstack/router-plugin` | devDependency | Vite plugin for file-based routing (includes `@tanstack/react-router`) |
| `@tanstack/router-devtools` | devDependency | Browser devtools for debugging routes |

### 2. Vite Configuration

**File:** `vite.config.ts`

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { tanstackRouter } from '@tanstack/router-plugin/vite'

export default defineConfig({
  plugins: [
    tanstackRouter({
      target: 'react',
      autoCodeSplitting: true,
    }),
    react(),
  ],
  server: {
    port: 3000,
  },
})
```

**Key points:**
- `tanstackRouter` must be placed **before** `react()` in the plugins array
- `target: 'react'` specifies the framework
- `autoCodeSplitting: true` enables automatic code splitting for routes

### 3. Main Entry Point

**File:** `src/main.tsx`

```typescript
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { RouterProvider, createRouter } from '@tanstack/react-router'
import { routeTree } from './routeTree.gen'
import './index.css'

const router = createRouter({ routeTree })

declare module '@tanstack/react-router' {
  interface Register {
    router: typeof router
  }
}

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <RouterProvider router={router} />
  </StrictMode>
)
```

**Key points:**
- `routeTree.gen.ts` is auto-generated by the router plugin
- The `Register` interface provides type safety for the router

### 4. Route Files

**Directory:** `src/routes/`

#### Root Layout (`__root.tsx`)

```typescript
import { createRootRoute, Outlet } from '@tanstack/react-router'
import { TanStackRouterDevtools } from '@tanstack/router-devtools'

export const Route = createRootRoute({
  component: RootComponent,
})

function RootComponent() {
  return (
    <>
      <header>
        <h1>Harmony App</h1>
      </header>
      <main>
        <Outlet />
      </main>
      {import.meta.env.DEV && <TanStackRouterDevtools position="bottom-right" />}
    </>
  )
}
```

#### Home Page (`index.tsx`)

```typescript
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/')({
  component: HomeComponent,
})

function HomeComponent() {
  return (
    <div>
      <h2>Home Page</h2>
      <p>Welcome to TanStack Router!</p>
    </div>
  )
}
```

### 5. Generated Files

The router plugin generates `src/routeTree.gen.ts` automatically when you run `npm run dev`.

**This file should be:**
- Ignored by ESLint (configured in `eslint.config.js`)
- Ignored by Prettier (configured in `.prettierignore`)
- Marked as read-only in VS Code (configured in `.vscode/settings.json`)

## ESLint & Prettier Setup

### 1. Dependencies Installed

```bash
npm install -D eslint @eslint/js typescript-eslint globals \
  eslint-plugin-react-hooks eslint-plugin-react-refresh \
  prettier eslint-config-prettier
```

### 2. ESLint Configuration

**File:** `eslint.config.js`

```javascript
import js from '@eslint/js'
import globals from 'globals'
import reactHooks from 'eslint-plugin-react-hooks'
import reactRefresh from 'eslint-plugin-react-refresh'
import tseslint from 'typescript-eslint'
import { defineConfig, globalIgnores } from 'eslint/config'
import eslintConfigPrettier from 'eslint-config-prettier'

export default defineConfig([
  globalIgnores(['dist', '**/*.gen.ts']),
  {
    files: ['**/*.{ts,tsx}'],
    extends: [
      js.configs.recommended,
      tseslint.configs.recommended,
      reactHooks.configs.flat.recommended,
      reactRefresh.configs.vite,
    ],
    languageOptions: {
      ecmaVersion: 2020,
      globals: globals.browser,
    },
  },
  eslintConfigPrettier,
])
```

**Key points:**
- Uses ESLint v9 flat config format
- `globalIgnores` excludes `dist` and generated files (`*.gen.ts`)
- `eslintConfigPrettier` must be last to disable conflicting rules

### 3. Prettier Configuration

**File:** `.prettierrc`

```json
{
  "semi": false,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5",
  "printWidth": 100
}
```

**File:** `.prettierignore`

```
dist
node_modules
*.min.js
*.gen.ts
```

### 4. npm Scripts

**File:** `package.json`

```json
{
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "lint": "eslint .",
    "lint:fix": "eslint . --fix",
    "format": "prettier --write \"src/**/*.{ts,tsx,css,json}\"",
    "format:check": "prettier --check \"src/**/*.{ts,tsx,css,json}\"",
    "preview": "vite preview"
  }
}
```

## VS Code Configuration

**File:** `.vscode/settings.json`

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "eslint.validate": ["javascript", "typescript", "typescriptreact"],
  "files.readonlyInclude": {
    "**/routeTree.gen.ts": true
  },
  "files.watcherExclude": {
    "**/routeTree.gen.ts": true
  },
  "search.exclude": {
    "**/routeTree.gen.ts": true
  }
}
```

**Features enabled:**
- Auto-format with Prettier on save
- Auto-fix ESLint issues on save
- `routeTree.gen.ts` marked as read-only
- `routeTree.gen.ts` excluded from search and file watcher
